# Updating the site (all from the GitHub website, no coding)

**Collection / status / contact:** open `data/collection.txt` > pencil icon > edit > *Commit changes*.
**Wishlist:** same, in `data/wishlist.txt`.
**Posters:** open the `image` folder > *Add file > Upload files*. Name each picture after the show (`falsettos.jpg`, `Dear Evan Hansen.png`).
The site refreshes about a minute after each commit.

# One-time setup

1. Create a GitHub repo, upload everything in this folder (*Add file > Upload files*).
2. *Settings > Pages > Deploy from a branch > main / (root)*. Your site goes live at `https://USERNAME.github.io/REPO/`.
3. Requests by email: go to https://web3forms.com, enter your email, copy the access key they send you, and paste it into `collection.html` where it says `PASTE_YOUR_ACCESS_KEY_HERE`. The key is safe to be public; it only lets people send *to you*.

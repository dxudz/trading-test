GitHub connection

One-time setup. The token lets this page save changes to your repo, so keep it private: only use it on devices you trust and never paste it into any of the site's files.

  1. On github.com open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories and pick this site's repo.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Pick an expiry date, generate, copy the token and paste it below.
